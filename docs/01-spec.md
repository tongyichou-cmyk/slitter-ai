# slitter.ai 完整規劃：Spec

版本：v2 草案（2026-11-09，待確認）
取代 v1。v1 的第 1 階段已上線，第 2 階段併入本版。

## 目標

讓 slitter.ai 成為 AI 與搜尋引擎願意引用的分條技術知識來源：

1. **讀得到**：爬蟲容易讀取，語系清楚，不重複。
2. **讀得懂**：每個主題只有一個權威頁面，網址穩定，中英文明確對應。
3. **信得過**：數字前後一致、有來源、有作者，並有第一手證據。

## 進度總覽

| 階段 | 內容 | 狀態 |
|---|---|---|
| 1. 止血 | 官網連結、公司規格、LINE、訂閱表單 | **已上線**（2026-11-09） |
| 2. 技術與語系 | 語系分離、關閉簡中、sitemap、結構化資料、全文版 | 待做 |
| 3. 內容結構與數據 | 最終網址、合併重複頁、權威數據表、統一數字 | 待做，需工程師確認數字 |

**上線方式**：第 2、3 階段一起上線，讓網址只改一次。第 4 階段之後陸續新增內容，不再改網址。

## 第 2 階段：技術與語系

沿用 v1 的需求 A1–A7（語系分離）與 C1–C8（技術清理），內容不變：

- 每篇文章只出現在實際使用的語言網址下；缺少翻譯就不提供，也不列入 sitemap 與列表。
- `hreflang` 與語言切換器只指向確實存在的版本。
- 介面文字依語系顯示；`html lang`、`og:locale` 正確。
- sitemap 收錄所有實際存在的頁面，日期使用內容的實際更新日期。
- 每頁只有一個 H1，Breadcrumb 結構化資料只輸出一次，作者標記為組織。
- 補上 favicon，並為每個語系各提供一份全文版。

### E. 權威數據表

| # | 需求 | 驗收方式 |
|---|---|---|
| E1 | 建立單一數據來源：各材料、厚度的建議間隙，毛邊高度上限，刀具材質比較 | 所有頁面、FAQ、結構化資料與計算機都讀同一份資料 |
| E2 | 每個數值都標示來源類型：公司實務、公開標準或文獻 | 數據表頁面顯示來源類型與審核日期 |
| E3 | 間隙建議以「材料＋厚度」分級，草案以英文間隙指南現有的厚度分級表為起點 | 工程師確認後才上線 |
| E4 | 沒有來源的數字，改為文字描述或移除，例如硬質合金壽命倍數、鋰電池隔離膜間隙精度、膜材 0–2% 間隙 | 全站搜尋不到未經確認的倍數與精度宣稱 |
| E5 | 間隙計算機使用同一份數據，並在結果下方說明依據與適用範圍 | 計算結果與數據表一致 |

### F. 用詞與可信度訊號

| # | 需求 | 驗收方式 |

## 第 4 階段：可信度與原創證據

這個階段需要公司提供資料，我負責整理、撰寫與上架。

| # | 內容 | 需要公司提供 |
|---|---|---|
| G1 | **具名審稿工程師**：姓名、職稱、年資、專長，各文章標示審稿人 | 1–2 位工程師同意具名 |
| G2 | **可查證的來源**：引用標準編號與官網產品規格 | 公司實際採用的標準，例如 JIS、ISO |
| G3 | **示意圖**：刀組結構、間隙定義、切口斷面四區域 | 無，我可繪製，請工程師確認正確性 |
| G4 | **實拍照片**：毛邊、邊波、刀痕、刀片磨耗前後對比 | 現場照片，可去除客戶資訊 |
| G5 | **匿名案例**：材料、厚度、問題、量測結果、調整方法、改善成果 | 3–5 個真實案例 |
| G6 | **新工具**：刀片周長與缺陷間距換算、鋼套組合計算 | 工程師確認計算方式 |
| G7 | **中英日術語表** | 公司慣用的日文術語 |
| G8 | **可下載規格表**：刀片、鋼套 | 官網現有規格即可 |

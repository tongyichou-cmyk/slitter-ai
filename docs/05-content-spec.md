# slitter.ai 內容擴充 Spec v1

狀態：草案，待確認（2026-11-10）

## 1. 目標

讓 slitter.ai 成為金屬分條領域會被 Google 和 AI 引用的一手資料來源。

成功的樣子：有人問 AI「how to reduce slitting burr」「分條刀間隙怎麼設定」「precision slitter knife manufacturer Taiwan」時，答案引用 slitter.ai 的頁面。

## 2. 原則

1. **只寫真的有根據的內容。** 數字要能指出來源：道德煜實務、標準或文獻。沒有來源的數字一律不寫，或改成文字描述。
2. **一手資料優先。** 工廠實測、照片、檢驗紀錄這類別人沒有的資料，價值高於再多一篇泛論文章。
3. **一個數字只有一個來源。** 新數據一律放進 `data/`，文章以元件引用，維持現有的檢查機制。
4. **中英文各自完整、不混用。** 同一篇在兩個語系都存在時，內容要對等。
5. **每篇有明確讀者與問題。** 不寫只為了湊關鍵字的文章。

## 4. 範圍：分四個階段

### 階段 0：統一技術說法（先做，約 1 天）

新文章會引用這些說法，所以要先統一。

- 由工程師確認一份「切口現象 ↔ 原因」對照：間隙過大或過小、刀具磨耗、壓入量各會造成什麼毛邊、塌角與斷面。
- 對照表寫進 `data/`，全站文章改成引用同一份。
- 沒有來源的張力、換線時間與成本倍數：工廠能提供依據就保留並標示來源，否則改成文字描述。

### 階段 1：中英文補齊（約 1–2 週）

| 工作 | 篇數 | 說明 |
|---|---|---|
| 繁中 → 英文 | 6 | knife-regrinding、hydraulic-nut、lightweight-spacers、stripper-rings、tooling-installation、slitting-clearance |
| 英文 → 繁中 | 3 | slitter-knife-materials、slitting-machine-selection、slitting-process |
| 繁中補深 | 視情況 | 繁中版明顯較短的文章，補到和英文同等的內容 |

- 英文版的 `slitting-clearance` 和間隙設定指南（guide）分工：前者講原理與診斷，後者講現場步驟，兩篇互相連結，不重複放數據表。
- 譯文不逐字翻譯，要符合各語系的業界用語。

### 階段 2：一手資料頁（依工廠能提供的資料決定）

這是最有引用價值的部分，**需要工廠提供資料**。我負責整理成數據頁、圖表與文章。

| 資料頁 | 需要的原始資料 | 有了之後能做什麼 |
|---|---|---|
| 切口圖鑑 | 各種間隙／刀況的切口斷面照片，並註明材料、厚度與間隙 | 「看照片判斷問題」的診斷頁，AI 與搜尋都很少有這種內容 |
| 刀軸跳動與寬度精度 | 跳動量實測值，以及對應的條寬量測紀錄 | 跳動 vs 精度的關係圖 |
| 毛邊量測紀錄 | 不同材料、間隙、刀具使用米數的毛邊高度 | 刀具磨耗曲線、研磨時機的實際依據 |
| 鋼套公差實測 | 出貨檢驗報告（可去識別化） | 證明 ±0.001 mm 的實際分布 |

只公開去識別化的資料，不出現客戶名稱。

### 階段 3：新文章（約 2–4 週，可與階段 2 並行）

| 文章 | 讀者 | 類型 |
|---|---|---|
| 刀軸跳動（Arbor Runout）完全解析 | 工程師 | 技術深度 |
| 分條寬度精度失效根因分析 | 品管、工程師 | 技術深度 |
| 換刀 SOP | 操作員 | 操作實務 |
| 分條機日常保養清單 | 操作員、保養 | 操作實務 |
| 如何評估分條刀與鋼套供應商 | 採購 | 選購決策 |

不在這次範圍：鎳基合金等工廠沒有實務經驗的材料，等有資料再寫。

## 5. 每篇文章的品質標準

- 開頭 2–3 句直接回答主要問題，方便 AI 摘錄。
- 至少 1 個表格或計算範例，數字來自 `data/` 或標示來源。
- 有 3–5 題 FAQ，寫在 frontmatter。
- 連到 2–4 篇相關文章，以及數據表或計算機。
- 具名作者：道德煜企業技術團隊；如果工程師同意，可以掛個人名字與職稱。
- 有實際照片時，附替代文字。
- 通過現有的測試：沒有手打的間隙或毛邊數字、沒有禁用語、中英文不混用。

## 6. 不做的事

- 不編造數據、測試結果或客戶案例。
- 不寫廣告文。產品只出現在文末的「相關產品」與 CTA。
- 不為了湊篇數寫內容重複的文章。

## 7. 成效追蹤

- **Search Console**：收錄頁數、曝光、點擊、平均排名，每月記錄一次。
- **AI 引用抽查**：每月用固定的 10 個問題問 ChatGPT、Perplexity、Gemini，記錄是否引用 slitter.ai。
- **詢價來源**：官網詢價表單或 LINE 詢問時，記錄客戶是否來自 slitter.ai。

## 8. 需要你確認

1. 四個階段的順序，以及階段 0 要先做。
2. 階段 2 中，工廠目前有哪些現成資料：照片、量測紀錄、檢驗報告。
3. 工程師能否具名，例如掛在作者欄。
4. 階段 3 的 5 篇新文章是否要增減。
